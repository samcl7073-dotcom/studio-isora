# Studio Isora — website

Studio site + development blog for studioisora.com. Plain HTML/CSS/JS generated by a small Python script, no dependencies. Hosted on DigitalOcean App Platform as a static site that serves the committed `dist/` folder.

## Edit, build, publish

```bash
python3 build.py          # regenerates dist/
python3 -m http.server 8000 -d dist   # preview at http://localhost:8000
git add -A && git commit -m "Update site" && git push   # DigitalOcean redeploys
```

Always run `python3 build.py` before committing; the live site is whatever is in `dist/`.

## Where things live

| To change… | Edit |
|---|---|
| Any text on the home page, nav, email | `content.json` |
| Booking link (Calendly, Cal.com, …) | `content.json` → `site.bookingUrl`. Empty = "Book" buttons open an email to info@. |
| Videos in "Watch the process" | `videos.json` — add `{ "title": "…", "youtube": "https://youtu.be/…" }` |
| Blog posts | `posts/YYYY-MM-DD-slug.md` (see below) |
| Layout | `templates/*.html` |
| Look | `styles.css` |

## Writing a blog post

Create `posts/2026-10-01-my-post.md`:

```markdown
---
title: My post title
date: 2026-10-01
summary: One or two sentences shown on the blog list and home page.
---

Paragraphs, **bold**, *italic*, [links](https://…), lists, and ## headings work.

https://youtu.be/VIDEO_ID

A YouTube link on its own line becomes an embedded video.

![Caption](/assets/blog/my-image.jpg)
```

The URL becomes `/blog/my-post/`. Images go in `assets/` (e.g. `assets/blog/`).
